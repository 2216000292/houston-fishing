钓法

绑钩和钓组分享

绑钩 4 种

🪢

帕洛马结

Palomar Knot
绑钩绑转环

最简单又牢靠的绑钩结，编织线、碳线都适合，新手先学这个。

怎么绑
  1. 线对折，把对折的线头穿过钩眼
  2. 用对折的两股线打一个松松的单结
  3. 把钩子从对折形成的线圈中穿过去
  4. 沾点水润湿，拉主线收紧，剪掉多余线头
🪢

改良克林奇结

Improved Clinch Knot
绑钩碳线 / 尼龙线

单丝线（碳线、尼龙线）绑钩最常用的结，钓场上最快。

怎么绑
  1. 线穿过钩眼，留出约 15 cm 线头
  2. 线头绕主线缠 5–7 圈
  3. 线头穿过钩眼旁边的小圈
  4. 再从刚形成的大圈里穿回来
  5. 沾水收紧，剪线头
🪢

双 Uni 结

Double Uni Knot
主线接子线

编织主线接碳线子线的简单接法，比 FG 结好学。

怎么绑
  1. 两根线并排重叠约 20 cm
  2. 用第一根线的线头打圈，绕另一根线 4–6 圈后收紧（编织线绕 8 圈左右）
  3. 另一根线头同样操作
  4. 拉两根主线，让两个结滑到一起贴紧
  5. 剪掉线头
🪢

FG 结

FG Knot
主线接子线路亚

编织线接碳线最细最牢的接法，过导环很顺，适合抛亮片、假饵。难度较高，建议对着视频多练。

怎么绑
  1. 绷紧编织主线
  2. 碳线在编织线上左右交叉缠绕约 20 次
  3. 用编织线在碳线上打几个半结固定
  4. 最后打一个收尾结，剪线头

钓组 6 种

🎣

沉底钓组

Carolina Rig
红鼓鱼黑鼓鱼比目鱼

最常用的底钓钓组，铅坠可以滑动，鱼咬饵时感觉不到重量。

主线→滑动铅→保护珠→转环→子线 60–90 cm→鱼钩
怎么做
  1. 主线依次穿过滑动铅和保护珠
  2. 主线绑上转环
  3. 转环另一头接 60–90 cm 子线
  4. 子线绑鱼钩，挂虾、蟹块或鱼块
  5. 水流急的堤上用 2–4 oz 的铅
🎣

响漂钓组

Popping Cork
斑点鳟鱼红鼓鱼

抽竿时浮漂会“啵”地响，模仿小鱼小虾吃东西的声音，把鱼引过来。

主线→响漂→子线 60–90 cm→鱼钩 + 活虾
怎么做
  1. 主线接响漂上端
  2. 响漂下端接 60–90 cm 碳线子线
  3. 子线绑钩，从虾头角下方挂活虾
  4. 抛出后每隔几秒抽一下竿，让浮漂响
🎣

串钩钓组

High-Low Rig
沙鳟鱼黄花鱼

一次能挂两个钩，钓沙鳟鱼、黄花鱼这类成群的小鱼效率很高。

主线→转环→支钩 ×2→底部铅坠
怎么做
  1. 主线接转环，下面接串钩线组
  2. 两个支钩分别挂虾肉
  3. 最下端挂 1–2 oz 铅坠
  4. 沉底后保持线绷紧，竿尖一抖就收线
🎣

双 Jig

Double Jig Rig
沙鳟鱼斑点鳟鱼

两个小铅头钩带软饵，上下跳动吸引鱼，不用带活饵。

主线→转环→上 Jig→下 Jig
怎么做
  1. 主线接转环，下面接双钩线组
  2. 上下各挂一个小铅头钩配软饵
  3. 沉到底后抬竿让饵跳起，再让它自然落下
  4. 咬口多在下落的时候
🎣

自由线

Free Line
羊头鱼斑点鳟鱼芒果鱼

不挂铅或只挂很小的铅，让活虾自然漂动，鱼最没戒心。

主线→转环→子线→鱼钩 + 活虾
怎么做
  1. 主线接转环，再接一段碳线子线
  2. 子线绑小钩，挂活虾
  3. 不加铅，或加一颗很小的咬铅
  4. 放线让虾顺着水流漂到石头边、桥墩边
🎣

鸡腿钓蟹

Chicken Neck Crabbing
蓝蟹

最简单的钓螃蟹方法，不需要鱼竿。

棉线→鸡腿→抄网
怎么做
  1. 棉线绑紧一只鸡腿，丢到水里
  2. 等线被拉直，说明螃蟹在吃
  3. 慢慢、匀速地把线往上拉，别停
  4. 螃蟹快出水时用抄网从下面捞
  5. 壳宽不够 5 inch 的放回去
